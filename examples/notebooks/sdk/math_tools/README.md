# Math Tools

Example math tools package generated from the SDK tutorial notebook.

## About

This package is generated by running `13_custom_functions_inline.ipynb`. The notebook
uses `%%writefile` magic to export production-ready functions to `math_tools/register.py`.

**Note**: The `math_tools/` subdirectory is created when you run the notebook.

## Installation

After running the notebook to generate the files:

```bash
cd examples/notebooks/sdk/math_tools
uv pip install -e .
```

## Available Functions

| Function | Description |
|----------|-------------|
| `Power` | Raise a base to an exponent (e.g., 2^3 = 8) |
| `SquareRoot` | Calculate square root (e.g., √16 = 4) |
| `AdvancedMathGroup` | Function group with factorial, logarithm, trigonometry, statistics |

## Usage

```bash
# Run via CLI
nat run --config_file ../configs/math_agent.yaml --input "What is 2^10?"
```
